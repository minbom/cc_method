# Hinge 관절 동심원 측정기

`index.html`을 브라우저(Chrome 권장)로 열어 쓴다. 설치·서버 불필요.

- DICOM은 브라우저 안에서만 읽는다. 업로드하지 않는다.
- 📂 파일 / 📁 폴더로 연다. 폴더로 열면 최상위 폴더 이름이 환자명에 들어간다.
- 기록은 브라우저 localStorage(`hinge_conc_v1`)에 측정자·회차·파일별로 저장된다. CSV는 측정자별(`측정자_hinge_YYYYMMDD.csv`), 1건 = 1줄.
- 지원 형식: 비압축 DICOM(Explicit/Implicit VR Little Endian). 압축 DICOM은 미지원.
- 계산은 mm 좌표(PixelSpacing 적용)에서 한다. 픽셀간격이 없으면 px 단위.

## 측정 순서 (동심원 측정)

| 단계 | 점 | 결과 |
|---|---|---|
| 1 | p1, p2, p3 | 세 점을 지나는 원 1 → 중심 c1, 반지름 r1 |
| 2 | p4, p5 | c1 중심 동심원 → r2 = (\|c1p4\| + \|c1p5\|)/2, a1 = ∠p4 c1 p5 (원호의 중심각) |
| 3 | p6, p7 | 반지름 r2로 p6·p7을 지나는 원 (중심 후보 2개 중 c1에 가까운 쪽 = c2) → a2 = 원호 p6p7의 원주각 (= 중심각/2) |

- 원호는 기본이 작은 호(≤180°). 패널의 `작은 호 ⇄` 버튼으로 큰 호로 바꾼다. 선택은 기록·CSV에 남는다.
- p6–p7 거리가 2·r2보다 크면 원 2를 만들 수 없어 저장을 막는다.
- 1단계 또는 2단계까지만 저장할 수 있다. 나머지는 N/A.
- CSV에는 a2 중심각, |c1p4|·|c1p5|, c1–c2 거리, p1–p7 좌표도 함께 나간다.

## 항목 추가

`MEASURES` 배열에 항목을 더하고, 계산·그리기·CSV 열(`COLS`)을 붙인다.
